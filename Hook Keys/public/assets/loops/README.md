# Loops nativos

Os MP3 fixos da playlist **Loops** ficam nesta pasta. A relação de arquivos e
nomes exibidos no app fica em `src/features/tracks/BundledLoops.ts`.

Todos os arquivos devem chegar editados para loop e exportados em **120 BPM**.
Somente eles e as playlists criadas com o tipo **Playlist de loop** acompanham
o BPM global do Hook Keys.
